# Help Translate Redrob Work

We are actively looking for contributors to translate Redrob Work to your own native language.

## README translations

README translations live alongside the main `README.md` in the repository root (`README_KO.md`, etc.).

If you want to add a new README language:

1. Copy `README.md` to a new file like `README_<LANG>.md` in the repository root.
2. Translate the content.
3. Add your new language link to the supported languages list at the bottom of `README.md`.
4. Open a PR.

## App UI translations (i18n)

You can also help translate the app UI via:

- `apps/app/src/i18n/`

Currently available app UI locales: English (`en`), Korean (`ko`).

Locale files live in `apps/app/src/i18n/locales/`.

If you are unsure where to start, open an issue and mention the language you want to contribute.
