Redrob Work Web is currently available for select customers. When your organization has it enabled, you can open a full Redrob Work instance in your browser. There is nothing to install and nothing to set up on your computer.

## Who can use it

Redrob Work Web is enabled per organization. If you do not see it in the sidebar, your organization does not have access yet — email [team@redrob.io](mailto:team@redrob.io) to request it.

Redrob Work Web is only available on hosted Redrob Work organizations. It is not available on self-hosted deployments.

## Open Redrob Work Web

1. Sign in to your organization dashboard.
2. Click `Redrob Work Web` in the sidebar.
3. Wait a few seconds while the workspace starts.
4. Open the new browser tab when it is ready.

  ![The Redrob Work Web page in the organization dashboard with the Open Redrob Work Web button](/images/cloud-redrob-web.png)
</Frame>

You are now looking at the full Redrob Work interface in your browser.

<Frame>
  ![Redrob Work Web open in a browser tab showing the full Redrob Work interface](/images/redrob-web-browser-tab.png)

## Sleep and persistence

The hosted instance sleeps when it is idle and wakes when you open it again. Files in the workspace persist across sleep, so you can close the tab and come back later without losing your work.

## Early-access limitation

During early access, the instance URL is itself the credential. Do not share it, paste it into public chats, or publish it anywhere public.

If you accidentally share the URL, ask an Redrob Work admin for help.
