`redrob-ui-mcp` is a local stdio MCP server that exposes the running Redrob Cowork
desktop app: its current screen, its open sessions, and every UI action available
right now. Codex spawns it as a local MCP server, so there is no URL, no OAuth, and
no account. Read the [overview](/model-context-protocol/overview) for the tool list
and how the bridge works.

## Setup

1. Launch the Redrob Cowork desktop app. The local control bridge starts with it.

2. Add the server:

   ```sh
   codex mcp add redrob-ui -- npx -y redrob-ui-mcp
   ```

3. Restart Codex, then confirm the connection:

   ```text
   Use ui_status to check whether Redrob Cowork is reachable.
   ```

## Manual config

Codex uses the same `mcpServers` shape as Claude Desktop, so you can edit its MCP
settings directly instead:

```json
{
  "mcpServers": {
    "redrob-ui": {
      "command": "npx",
      "args": ["-y", "redrob-ui-mcp"]
    }
  }
}
```
