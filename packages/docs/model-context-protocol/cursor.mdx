`redrob-ui-mcp` is a local stdio MCP server that exposes the running Redrob Work
desktop app: its current screen, its open sessions, and every UI action available
right now. Cursor spawns it as a local MCP server, so there is no URL, no OAuth, and
no account. Read the [overview](/model-context-protocol/overview) for the tool list
and how the bridge works.

## Setup

1. Launch the Redrob Work desktop app. The local control bridge starts with it.

2. Add the server to `~/.cursor/mcp.json` for every project, or `.cursor/mcp.json`
   for one project:

   ```json
   {
     "mcpServers": {
       "redrob-ui": {
         "command": "npx",
         "args": ["-y", "redrob-ui-mcp"]
       }
     }
   }
   ```

3. Open Cursor `Settings` > `MCP` and confirm `redrob-ui` is running.

<Note>
Cursor Web and Cursor Agents run away from your machine, so they cannot reach the
Redrob Work bridge on `127.0.0.1`. Use Cursor Desktop.
</Note>
