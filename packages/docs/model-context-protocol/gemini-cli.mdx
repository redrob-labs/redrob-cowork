`redrob-ui-mcp` is a local stdio MCP server that exposes the running Redrob Cowork
desktop app: its current screen, its open sessions, and every UI action available
right now. Gemini CLI spawns it as a local MCP server, so there is no URL, no OAuth,
and no account. Read the [overview](/model-context-protocol/overview) for the tool
list and how the bridge works.

## Setup

1. Launch the Redrob Cowork desktop app. The local control bridge starts with it.

2. Add the server:

   ```sh
   gemini mcp add redrob-ui npx -y redrob-ui-mcp
   ```

3. Start Gemini CLI and list the servers:

   ```sh
   gemini
   ```

   ```text
   /mcp
   ```

## What you can ask

- "Use `ui_status` to check whether Redrob Cowork is reachable."
- "List my Redrob Cowork sessions, then open the one about the customer migration."
- "Type a summary request into the Redrob Cowork composer and send it."
