The Redrob Work MCP server ([Redrob Work Connect](/cloud/run-in-the-cloud/cloud-mcp))
enables Gemini CLI to use the Redrob Work capabilities your organization has made
available to you: Gmail read/search, Calendar list/create, Drive search/read,
Gmail draft creation, shared MCP connections such as Notion, Linear, Slack,
Stripe, Exa, and Context7, shared skills, and Redrob Work Cloud resources like
skills, plugins, Collections, workers, members, roles, teams, and LLM
providers. The server exposes only `search_capabilities` and
`execute_capability`, so Gemini CLI searches what you can access and runs exact
capability names instead of loading hundreds of tool definitions into context.

## Server URL

```text
https://api.redrob.io/mcp/agent
```

OAuth sign-in uses your Redrob Work account, and the organization you pick is
pinned into the token. If you do not have an account, create a
[free Redrob Work account](https://app.redrob.io?mode=sign-up).

## Setup

1. Add Redrob Work Connect as a remote HTTP MCP server:

   ```sh
   gemini mcp add --transport http redrob https://api.redrob.io/mcp/agent
   ```

2. Start Gemini CLI:

   ```sh
   gemini
   ```

3. Authenticate Redrob Work inside Gemini:

   ```text
   /mcp auth redrob
   ```

4. Finish the browser sign-in and choose your organization.

## Switch organizations

Remove the stored MCP auth token for `redrob`, then run `/mcp auth redrob`
again and choose the organization you want during browser sign-in.

<Note>
This is a setup guide. These steps match Redrob Work Connect's OAuth profile:
HTTPS or HTTP loopback callbacks, PKCE S256, and dynamic client registration
fallback. Gemini CLI is listed as setup only because native proof is not
complete. See the
[client support status](/cloud/run-in-the-cloud/cloud-mcp#client-support-status)
table.
</Note>
