`redrob-ui-mcp` is a local stdio MCP server that exposes the running Redrob Work
desktop app: its current screen, its open sessions, and every UI action available
right now. Claude Code spawns it as a local MCP server, so there is no URL, no OAuth,
and no account. Read the [overview](/model-context-protocol/overview) for the tool
list and how the bridge works.

## Setup

1. Launch the Redrob Work desktop app. The local control bridge starts with it.

2. Add the server:

   ```sh
   claude mcp add redrob-ui -- npx -y redrob-ui-mcp
   ```

   Add `-s user` to make it available in every project.

3. Open Claude Code, run `/mcp`, and confirm `redrob-ui` is connected.

## What you can ask

- "Use `ui_status` to check whether Redrob Work is reachable."
- "List my Redrob Work sessions, then open the one about the customer migration."
- "Type a summary request into the Redrob Work composer and send it."
- "Read the transcript of my last Redrob Work session and tell me what is unresolved."
