`redrob-ui-mcp` is a local stdio MCP server that exposes the running Redrob Cowork
desktop app: its current screen, its open sessions, and every UI action available
right now. VS Code spawns it as a local MCP server, so there is no URL, no OAuth, and
no account. Read the [overview](/model-context-protocol/overview) for the tool list
and how the bridge works.

## Setup

1. Launch the Redrob Cowork desktop app. The local control bridge starts with it.

2. Add the server:

   ```sh
   code --add-mcp '{"name":"redrob-ui","type":"stdio","command":"npx","args":["-y","redrob-ui-mcp"]}'
   ```

3. Open the Command Palette, run `MCP: List Servers`, select `redrob-ui`, then
   `Start Server`.

## Manual setup

Run `MCP: Open User Configuration`, or edit `.vscode/mcp.json` for one workspace:

```json
{
  "servers": {
    "redrob-ui": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "redrob-ui-mcp"]
    }
  }
}
```

Then run `MCP: List Servers` > `redrob-ui` > `Start Server`.
