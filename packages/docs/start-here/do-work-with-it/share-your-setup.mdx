<Note>
**The Library is local.** It lists what this workspace and your home directory
actually contain. Nothing is assigned to you from elsewhere, and nothing you add is
shared until you copy it somewhere.
</Note>

## Find your skills

1. Open `Settings > Library` in the desktop app.
2. Use the `Skills` filter or search.
3. Click a skill and choose `View details` to read its description, reveal the file on
   disk, or remove it.
4. Click `Refresh` after you add or edit a `SKILL.md` outside the app.

The list covers the current workspace and its parent directories up to the `.git`
boundary, plus the global skill directories in your home folder. See
[Create a skill from chat](/start-here/do-work-with-it/create-a-skill-from-chat) for
the exact paths.

## Share one

Skills are plain files, so sharing is copying. Commit them to a repository you already
share, or publish a plugin repository teammates install on purpose. Both paths are in
[Share and copy a skill](/start-here/do-work-with-it/publish-and-copy-a-skill).

## Share the MCP servers too

MCP connections are not files in your workspace, so they do not travel with a skill
directory. Two options:

- Bundle them in a plugin repository through its `.mcp.json`. Installing the plugin
  registers the servers.
- Have each person add the server themselves with
  [Add an MCP server](/start-here/connect-your-stack/add-an-mcp-server). Credentials
  are per person in either case.
