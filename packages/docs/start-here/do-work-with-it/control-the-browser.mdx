---
title: "Control the browser"
description: "How to use Redrob Cowork to automate the built-in browser"
---

Computer-use in Redrob Cowork currently works through the built-in Redrob Cowork Browser. It does not yet mean full desktop control of Ubuntu, macOS, or Windows apps.

Redrob Cowork can open pages, click, fill forms, read page content, and take screenshots inside that browser. If you connect to a remote Redrob Cowork server, the browser runs on that remote worker.

Today, the supported path is the first-party `Redrob Cowork Browser` extension.

## Requirements

- Use the desktop app or a remote worker that exposes the Redrob Cowork Browser.
- Keep `Redrob Cowork Browser` enabled in `Settings > Library`.

Then go back to the session view and ask Redrob Cowork to open a website.
