---
title: "Control the browser"
description: "How to use Redrob Work to automate the built-in browser"
---

Computer-use in Redrob Work currently works through the built-in Redrob Work Browser. It does not yet mean full desktop control of Ubuntu, macOS, or Windows apps.

Redrob Work can open pages, click, fill forms, read page content, and take screenshots inside that browser. If you connect to a remote Redrob Work server, the browser runs on that remote worker.

Today, the supported path is the first-party `Redrob Work Browser` extension.

## Requirements

- Use the desktop app or a remote worker that exposes the Redrob Work Browser.
- Keep `Redrob Work Browser` enabled in `Settings > Library`.

Then go back to the session view and ask Redrob Work to open a website.
