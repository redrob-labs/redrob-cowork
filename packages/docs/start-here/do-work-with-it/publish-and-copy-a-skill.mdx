---
title: "Share and copy a skill"
description: "Hand a skill to a teammate by copying its files or by publishing a plugin repository on GitHub"
---

<Note>
**Sharing is a copy, not an assignment.** Redrob Cowork has no control plane, so nothing
pushes a skill to someone else's machine or updates it later. You either hand over the
files or publish a plugin repository they choose to install.
</Note>

## Option 1: copy the files

A skill is a directory with one file in it. Send it, commit it, or drop it in shared
storage:

```text
.opencode/skills/<skill-name>/SKILL.md
```

The recipient puts that directory under `.opencode/skills/` in their own workspace, or
under `~/.config/opencode/skills/` to have it everywhere. It shows up in
`Settings` > `Library` after a refresh.

Committing skills to the repository you already share is the simplest version of this.
Everyone who clones the repo gets the skills with it.

## Option 2: publish a plugin repository

For several skills, commands, agents, or MCP servers that belong together, package
them as an Anthropic-compatible plugin bundle in a public GitHub repository. Redrob
Work installs those directly.

1. Create a public GitHub repository laid out as a Claude Code plugin: skills under
   `skills/<name>/SKILL.md`, commands, agents, and an optional `.mcp.json` for bundled
   MCP servers.
2. Push it.
3. Each teammate opens `Settings` > `Library`, expands `Advanced settings`, and imports
   the plugin from GitHub by pasting `https://github.com/<owner>/<repo>`.
4. Redrob Cowork previews what the bundle contains, asks for approval, then installs the
   skills and registers any bundled MCP servers with the running engine.

Only public repositories work. Redrob Cowork fetches the bundle from GitHub without a
token, so a private repository returns nothing.

To ship an update, push to the repository and have people reinstall. There is no
automatic update channel.

## Copy without changing the original

To adapt a skill you received, copy its directory to a new name and edit the copy.
Editing the original means your change disappears the next time that skill is
reinstalled from its source.

For a small adjustment, write a short new skill that tells the agent to follow the
original first, then apply your extra instructions.
