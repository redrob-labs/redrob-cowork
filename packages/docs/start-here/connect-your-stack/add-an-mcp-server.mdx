title: "Add an MCP server"
description: "Connect any MCP server to a Redrob Cowork workspace"
---

<Note>
**Local workspace setup.** MCP servers are added per workspace, on your machine, with no account and no organization. Credentials are stored locally by `redrob-server` and passed to the Redrob Code engine.
</Note>

Adding an MCP server is how you give the Redrob Cowork agent access to a system: Slack,
Notion, Linear, GitHub, your own internal service, or a local process. This is the
only way to connect a service. There is no managed catalog to pick from.

For a walkthrough of the vocabulary around connections and plugins, see
[Connect your services](/start-here/connect-your-stack/connect-services).

Connecting an app with Redrob Cowork takes four clicks.

- In the desktop app, open `Settings` \> `Library`, expand `Advanced settings`, then click `Add workspace MCP`

<Frame>
  ![Library page with Advanced settings expanded, showing the Add workspace MCP button](/images/library-advanced-settings.png)
</Frame>

The MCP is added to the current workspace.

<Frame>
  ![Add workspace MCP dialog with app name, server URL, and OAuth options](/images/library-add-mcp-modal.png)

  Indicate whether the server requires OAuth.
</Frame>

This setup is intended for servers that support dynamic OAuth client registration.

<Frame>
  ![OAuth approval page for MCP server](/images/mcp-oauth-approval-page.png)
</Frame>

Complete the provider's OAuth approval flow in your browser. It should redirect
back to Redrob Cowork. If a custom MCP needs behavior Redrob Cowork does not support,
[open an issue](https://github.com/redrob-labs/redrob-work/issues/).

### Troubleshooting

Some MCP servers do not support dynamic client registration. If the server gives you a pre-registered OAuth client ID and client secret, add it through `Add workspace MCP` > `OAuth on this device`.

For an advanced local Slack setup, follow
[Connect Slack as a custom MCP](/start-here/connect-your-stack/connect-slack-mcp).
