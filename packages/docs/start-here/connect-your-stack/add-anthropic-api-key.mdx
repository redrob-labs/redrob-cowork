<Note>
**Local provider setup.** The key you add here stays on your machine, in your own desktop app. Redrob Work is free and has no account to sign in to. The default provider is Redrob, connected with a Redrob Key from [console.redrob.ai](https://console.redrob.ai); Anthropic is an additional provider you bring yourself.
</Note>

Anthropic has disabled 3rd party authentication for their OAuth. In order to continue supporting Anthropic based models in Redrob Work, we now default to manual API key entry for Anthropic.
That means you create the key in Anthropic first, then paste it into Redrob Work.

## Before you start

- You need an Anthropic account at [platform.claude.com](https://platform.claude.com).
- Your Claude subscription and your Anthropic API billing are not always the same thing, so make sure API access is enabled on your Anthropic account.
- Treat the key like a password. Anthropic will only show the full value when you create it.

Each person adds their own key. There is no central place to provision Anthropic access for a group, so a teammate who needs Anthropic models creates a key on their own account and repeats these steps.

## Create the key in Anthropic

1. Sign in at [platform.claude.com](https://platform.claude.com).
2. Open the `API Keys` page.

<Frame>
  ![Anthropic API Keys page](/images/anthropic-key.png)
</Frame>

3. Click `Create Key`.
4. Give the key a recognizable name like `Redrob Work`.

<Frame>
  ![Anthropic Create Key dialog](/images/anthropic-redrob-key.png)
</Frame>

5. Copy the new key right away. It should look like `sk-ant-...`.

## Add the key to Redrob Work


1. Open `Settings` in Redrob Work.
2. Go to `Connect Provider` and choose `Anthropic`.
3. Paste the API key into the manual key field.
4. Save the provider, then choose an Anthropic model in chat.

<Frame>
  ![How to add a new provider in Redrob Work](/images/redrob-providers.png)
</Frame>

## Common issues

- If the key is rejected, make sure you copied the full value without extra spaces.
- If you cannot see `API Keys`, check that your Anthropic account has API access and billing set up.
- If you lose the key, create a new one in Anthropic and update Redrob Work with the new value.

The same general process applies to most providers that use manual API keys: create the key in the provider's developer console, copy it once, and paste it into Redrob Work.
