OpenCode and OpenCode Go models are provided by OpenCode, not Redrob. If you have an OpenCode subscription or API key, connect the `OpenCode Go` provider in the Redrob desktop app.

<Note>
OpenCode and Redrob Cowork model subscriptions are separate. If you are unsure which one you have, see [Redrob Cowork vs OpenCode models](/start-here/connect-your-stack/redrob-vs-opencode-models).
</Note>

## Connect OpenCode Go in Redrob Cowork Desktop

1. Open Redrob Cowork Desktop.
2. Click your avatar in the bottom-left corner.
3. Open `Settings`.
4. Go to `AI Providers`.
5. Click `Connect`.
6. Search for `opencode`.
7. Choose `OpenCode Go`.
8. Click `Connect` and enter your OpenCode API key when prompted.

<Frame>
  ![OpenCode Go provider in the Connect providers dialog](/images/opencode-go-connect-provider.png)
</Frame>

After the provider is connected, choose an OpenCode model from the model picker in a chat.

## Manage your OpenCode account

- Learn about OpenCode Go at [opencode.ai/go](https://opencode.ai/go).
- Manage your OpenCode account or authentication at [opencode.ai/auth](https://opencode.ai/auth).

If Redrob says the OpenCode key is invalid or the model is unavailable, check your OpenCode account first. Redrob does not manage OpenCode Go or OpenCode billing.
